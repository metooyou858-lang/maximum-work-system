# Активные проблемы и блокеры

В этом документе находятся только нерешённые проблемы. Устранённые пункты удаляются отсюда после проверки результата на VPS.

## ISSUE-001 — два контура вместо единой системы

- **Симптом:** основной сценарий сотрудника и рабочий кабинет руководителя работают через разные серверы и SQLite-файлы.
- **Факт проверки:** основной сервис — `maximum` на 4173, рабочий кабинет — `maximum-work` на 4174.
- **Причина:** функции переносились частями из разных веток и не были собраны в один вертикальный сценарий.
- **Следующее действие:** спроектировать и реализовать единый серверный контур с общей базой, затем проверить старые функции.

## ISSUE-002 — Яндекс Карты возвращают `403 Invalid api key`

- **Симптом:** API-ключ задан на VPS и ограничен доменами, но загрузка JS API не принята.
- **Факт проверки:** запрос с VPS возвращал `403 Invalid api key`.
- **Следующее действие:** после окна активации нового ключа повторить проверку HTTPS и пройти полный сценарий постановки точки.

## ISSUE-003 — карта отсутствует в рабочей карточке объекта

- **Симптом:** в рабочем кабинете при создании объекта доступно только поле адреса.
- **Факт проверки:** `work-server.mjs` и `public/work-cabinet.js` не содержат координат, радиуса и загрузки Яндекс API.
- **Причина:** интеграция карты осталась в старом `server.mjs` и не была перенесена в рабочий контур.
- **Следующее действие:** реализовать карту только как часть объединённого сценария объекта, а не отдельной копией.

## ISSUE-004 — приглашение и логин сотрудника не завершены

- **Симптом:** при создании карточки создаётся `pending_activation`, но сотрудник не получает приглашение и не может войти по своей учётной записи.
- **Следующее действие:** реализовать активацию по email и проверить вход сотрудника на VPS синтетическими данными.
