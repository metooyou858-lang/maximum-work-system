# Активные проблемы и блокеры

В этом документе находятся только нерешённые проблемы. Устранённые пункты удаляются отсюда после проверки результата на VPS.

## ISSUE-001 — два внутренних процесса вместо одного приложения

- **Симптом:** основной сценарий сотрудника и рабочий кабинет руководителя пока обслуживаются двумя systemd-процессами.
- **Факт проверки:** оба доступны через единый числовой домен; рабочий кабинет — `/manager/`, данные хранятся в общей `demo.sqlite`.
- **Причина:** функции переносились частями из разных веток.
- **Следующее действие:** объединить серверные маршруты в один процесс после отдельной проверки полного сценария и без потери текущих функций.

## ISSUE-002 — рабочая карточка объекта ещё не связана со сценарием сотрудника

- **Симптом:** точка объекта сохраняется в рабочей карточке, но сотруднический сценарий пока использует демонстрационный объект.
- **Факт проверки:** объект с координатами и радиусом создан через общий домен и сохранён в общей SQLite-базе.
- **Следующее действие:** связать назначения, геопроверку и отчёт с объектами из рабочего реестра.

## ISSUE-003 — приглашение и рабочий кабинет сотрудника не завершены

- **Симптом:** единая стартовая форма авторизации уже принимает учётные записи обоих ролей, но при создании карточки создаётся только `pending_activation`; активация, приглашение и рабочий раздел сотрудника ещё не подключены.
- **Следующее действие:** реализовать активацию по email и проверить вход сотрудника на VPS синтетическими данными.

## ISSUE-004 — для подтверждения адреса нужен доступ к геокодеру Яндекс

- **Симптом:** карта и выбор Хабаровска работают, но запрос подтверждения адреса на VPS получает отказ Яндекса; текущий ключ разрешает карты, но не геокодирование.
- **Факт проверки:** `Хабаровск, улица Ленина, 1` не подтверждён через HTTPS-контур; сохранение без подтверждения заблокировано сервером.
- **Следующее действие:** добавить отдельный ключ/разрешение Яндекс Геокодера в закрытое окружение VPS и повторить браузерную проверку.
