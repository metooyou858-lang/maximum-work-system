# Карта проекта MAXIMUM

Этот файл — общий вход для владельца и исполнителей. Перед крупной правкой прочитать его, затем профильный документ из `docs/`.

## Назначение

Система учёта работ, сотрудников и оборудования компании MAXIMUM. Первая версия охватывает объекты, назначения конкретных сотрудников и оборудования, личные отметки прибытия и персональные отчёты. Производство, продажи, финансы и расчёт зарплаты не входят автоматически в этот объём.

Актуальные продуктовые решения — в «Решения после совещания 26.09.2026.md». Краткое описание для владельца — «Описание проекта.md».

## Структура репозитория

- `server.mjs` — сервер приложения и SQLite-логика.
- `work-server.mjs` — отдельный рабочий контур кабинета руководителя с карточками сотрудников и серверными сессиями; пока только синтетические данные, приглашение сотрудника не реализовано.
- `public/work-cabinet.*` — интерфейс рабочего кабинета руководителя, опубликованный на втором HTTPS-адресе VPS.
- `public/` — общий интерфейс кабинета.
- `tests/` — серверные и браузерные проверки; приёмочные запуски только на VPS.
- `ops/` — подключение, диагностика и служебные сценарии VPS.
- `phone-demo/` — архивная статическая телефонная демонстрация, не тестовый контур.
- `docs/` — постоянная документация проекта.
