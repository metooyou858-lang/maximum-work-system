# Статус реализации и поставки

Этот документ показывает, что реализовано, что фактически развернуто на VPS и что проверено. Строка не считается готовой только потому, что код существует.

| Область | В исходниках | На VPS | Проверено | Состояние |
|---|---|---|---|---|
| VPS, HTTPS, Caddy, PostgreSQL, резервные копии | Да | Да | Да | PostgreSQL 16 установлен на VPS; единственный рабочий процесс использует базу `maximum`, `pg_dump` проверен созданием дампа, исходный SQLite сохранён отдельно |
| Единая стартовая авторизация | Да | Да | Да | Корневой адрес ведёт на `/manager/`; демонстрационный экран больше не является стартовой страницей |
| Карточка объекта с подрядчиком, координатами и радиусом | Да | Да | Частично | Наименование подрядчика сохраняется в PostgreSQL; выбранная точка и радиус отображаются на карте кругом. Служба и миграция на VPS проверены, финальная визуальная проверка новой формы ожидает восстановленной авторизованной вкладки |
| Рабочий кабинет руководителя | Да | Да | Да | Доступен через единую стартовую авторизацию на `/manager/` |
| Поля карточки сотрудника | Да | Да | Да | ФИО, email, телефон, фото, дата рождения, одежда, обувь |
| Объект с картой в рабочем кабинете | Да | Да | Да | Рабочий кабинет на общем домене `/manager/`; карта и повторное открытие точки проверены браузером на VPS |
| Подтверждение адреса через геокодер | Да | Да | Да | На VPS проверены загрузка JS API, автоподсказки и выбор синтетического адреса «Хабаровск»; координаты и флаг подтверждения передаются в сохранение карточки |
| Логин и приглашение сотрудника | Частично | Частично | Нет | Есть `pending_activation`, полноценное приглашение не реализовано |
| Общий числовой домен и одна PostgreSQL-база | Да | Да | Да | `89-125-214-188.sslip.io`, рабочий процесс использует базу `maximum`; проверены редирект корня, health 200 и список объектов |
| Один рабочий процесс приложения | Да | Да | Да | Старый `maximum.service` отключён; Caddy публикует только `maximum-work.service` |

## Правило статусов

- **В исходниках** — функция есть в рабочей папке.
- **На VPS** — функция попала в задеплоенную версию.
- **Проверено** — функция прошла соответствующую серверную или браузерную проверку на VPS.
- **Готово** — все три условия выполнены и нет активного блокирующего пункта.

После каждого этапа обновлять эту таблицу и указывать дату проверки в коммите или передаче результата.
