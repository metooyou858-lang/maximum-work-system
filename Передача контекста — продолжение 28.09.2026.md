## Что создано локально

- Локальный веб-кабинет доступен по `http://127.0.0.1:4173/cabinet`; backend — `server.mjs`, база — SQLite `data/demo.sqlite`, интерфейс — `public/`.
- В боковой навигации три стартовых справочника: «Мои объекты», «Сотрудники», «Оборудование».
- В объекте пока фиксируется адрес; следующее развитие карточки — интерактивная карта с поиском, маркером, координатами и позднее радиусом. Карта должна быть именно в карточке объекта.
- В сотруднике: ФИО, дата рождения, возраст, размеры одежды и обуви (выпадающие списки), тестовая фиксация ознакомления с политикой. Версия политики устанавливается сервером, не вручную в карточке. Фото и документы не добавлены.
- В оборудовании: название, инвентарный номер, тип.
- На пустых списках оставлена только одна кнопка создания — в заголовке; дублирующая кнопка убрана.
- `npm test` проходил после последних изменений. Изменения `server.mjs` требуют перезапуска локального Node-сервера.

## Направление продукта

Три справочника — не конечная структура рабочего места, а данные компании. Следующая ключевая сущность — **назначение работ**: объект + конкретные сотрудники + оборудование + плановые даты/статус. Из назначений строится рабочая страница руководителя: активные объекты, кто назначен, прибытия, личные отчёты и результаты.

Рабочая гипотеза навигации после появления назначений:

1. Рабочий день / активные работы.
2. Мои объекты.
3. Данные компании: сотрудники и оборудование.
4. Настройки.

Это направление, не утверждённый финальный дизайн. Не переносить визуальный стиль сторонних CRM целиком: брать можно только проверенный сценарий управления работой.

## Внешние сервисы и карта

- Выбранное направление — API Яндекс Карт. API-ключ не хранить в исходниках, документах или чате.
- В «Настройки → Подключения» должны быть поставщик карт, ключи и проверка подключения, чтобы сервис можно было заменить. Карта и выбор координат остаются в объекте.
- Перед добавлением ключа в браузерный API ограничить его разрешёнными origin/referrer; изменение настроек в кабинете Яндекса делать только после прямого подтверждения владельца.
