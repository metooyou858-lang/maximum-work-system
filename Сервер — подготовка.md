## Подключение и дальнейшая работа

```powershell
ssh -i "$env:USERPROFILE\.ssh\maximum_vps" -o IdentitiesOnly=yes -p 41480 maximum-admin@93.88.203.94
```

Ключ требует парольную фразу из локального DPAPI-хранилища. При автоматизации передавать её в скрытый запрос SSH, не в аргументы команды и не в журналы. Приватный ключ и DPAPI-файлы нельзя пересылать в чат.

Для будущего приложения на `127.0.0.1:8080` добавить к SSH `-N -L 127.0.0.1:8080:127.0.0.1:8080`; затем открыть `http://127.0.0.1:8080`. Пока приложение на этом порту не запущено.

Исходники настроек: `ops/prepare-test-vps.sh`, `ops/harden-ssh.sh`. Второй сценарий применяется только после проверки отдельного входа администратора, с автоматическим откатом через 5 минут. После успешного повторного подключения таймер отката был остановлен.

Перед реальными данными выполнить условия из «Персональные данные — условия запуска.md». На данном этапе соответствие рабочей системы 152-ФЗ не подтверждено.
